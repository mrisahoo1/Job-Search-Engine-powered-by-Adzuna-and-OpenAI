# Contract: Resume Tailoring

## Input

- Candidate resume text.
- Selected job posting.
- Fit evaluation.
- Optional user instructions.

## Output

- Tailored resume draft text.
- Change summary.
- Warnings for missing skills or unsupported claims.
- Suggested keywords to add only if truthful.

## Rules

- Do not invent employers, dates, metrics, degrees, certifications, or tools.
- Prefer reordering and emphasizing existing evidence over creating new claims.
- Preserve a recoverable base resume.
