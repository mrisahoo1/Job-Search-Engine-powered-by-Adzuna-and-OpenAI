# Contract: Outreach Drafting

## Input

- Candidate profile summary.
- Selected job posting.
- Fit evaluation.
- Target persona or named contact if reliably known.
- Desired channel: LinkedIn, email, or short text.

## Output

- Message draft.
- Suggested subject line for email.
- Target persona rationale.
- Search link hints when named contacts are unavailable.

## Rules

- Do not claim a referral, relationship, interview, or application submission that has not happened.
- Keep LinkedIn-style drafts concise.
- Require user review before sending or copying into an external application workflow.
