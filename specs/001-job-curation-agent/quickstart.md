# Quickstart: Job Search and Curation Agent

## Local Setup

1. Install dependencies with `npm install`.
2. Run tests with `npm test`.
3. Start the app with `npm run dev`.
4. Open the local URL shown by Vite.

## MVP Scenario

1. Paste a resume into the resume panel.
2. Confirm EU region is active and remote or visa sponsorship preferences are set.
3. Run a job search.
4. Review ranked job cards with fit explanations, source attribution, remote and visa signals, and apply links.
5. Select a promising job.
6. Generate a tailored resume draft and review the change summary.
7. Generate LinkedIn and email outreach drafts.
8. Save the job to prospects and update status or notes.

## Verification Scenario

1. Use a resume containing TypeScript, React, Node.js, APIs, and cloud deployment.
2. Search for `software engineer` with EU active and visa sponsorship preferred.
3. Confirm the app returns normalized jobs or seeded fallback examples if public sources are temporarily unavailable.
4. Confirm each job has source attribution and no external application is submitted automatically.
